## 硬边界

- 每个 CLI 动作都绑定配置哈希、运行器哈希、输入哈希、资源类别和输出路径，并使用独立批准记录。
- 模型和 tokenizer 只从已核验本地目录加载；禁止联网补下载和远程代码。
- 私钥只保存在 Git 忽略目录；作用域仅记录密钥文件 SHA-256，不记录密钥值。
- 外部 MarkLLM 仓库必须保持固定提交且工作树干净。
- 长任务写入可恢复的 partial 文件；已有完成输出不得覆盖。
- 任一步出现哈希漂移、非有限数、CUDA 异常或协议不满足时停止当前步骤，不自动扩大范围。
